## Hello, World!

{/* TODO: short intro - why you're back to writing, why tokens/context matter now */}

- Newer models are smarter but pricier; token spend adds up fast in local agentic workflows
- Most of the waste is noise: verbose shell output, re-reading the same files, re-explaining context every new session
- Three tools, three layers: shell output (rtk), context/payloads (headroom), memory across sessions (mempalace)

## rtk - Rust Token Killer

<GithubLink url="https://github.com/rtk-ai/rtk">
  > {/* TODO: one-paragraph summary in your words */}
  > A CLI proxy that filters and compresses the output of everyday dev commands before it reaches the agent.
</GithubLink>

{/* TODO: write up */}

- Installs as a Claude Code hook that transparently rewrites commands (`git status` → `rtk git status`)
- Condenses output of `git`, `ls`, `grep`, test runners, `gh` and more
- `rtk gain` shows how many tokens you've saved; `rtk discover` finds commands you missed
- Caveat: the filtered output is sometimes too aggressive (mangled `find` paths, collapsed diffs) - `rtk proxy <cmd>` runs the raw command when the agent needs exact output

## headroom - context compression

<GithubLink url="https://github.com/headroomlabs-ai/headroom">
  > {/* TODO: one-paragraph summary in your words */}
  > Compresses the context sent to LLM APIs, either as a proxy/gateway in front of the provider or as an MCP server the agent calls on demand.
</GithubLink>

{/* TODO: write up */}

- Works well as a gateway for any OpenAI-compatible API - point the client at headroom instead of the provider
- Can also run as an MCP server (`headroom mcp serve`) for on-demand compression/retrieval

<Highlight block color="pink">
  > #### Claude Code on a subscription
  >
  > {/* TODO: describe your experience */}
  > Routing Claude Code through the headroom gateway while on a subscription plan leads to session corruption - conversations break and can't be continued.
  > For local dev with Claude Code, skip the gateway and stick to the MCP integration (or use the gateway only with API-key billing / OpenAI-like APIs).
</Highlight>

## mempalace - long-lasting memory

<GithubLink url="https://github.com/mempalace/mempalace">
  > **Mem Palace** stores your conversations in a searchable form, in order to keep reasoning behind decisions in the loop. It **works as a local MCP service**, which can scan/learn from existing codebase and will auto-learn as you use it.
  >
  > `Fun Fact:` the data model is inspired by Roman and Greek "Memory Palace" concept and projects, topics and so on are organised in wings, rooms and drawers.
</GithubLink>

{/* TODO: write up */}

- Released by [Milla Jovovich](https://github.com/milla-jovovich), star of [The Fifth Element](https://www.imdb.com/title/tt0119116/)
- Mines existing projects and conversation history; semantic search filtered by wing/room
- Answers "why was it built this way", which `git log` and task trackers don't capture
- Fewer "re-read the codebase" errands at the start of every session
